# AutoMagik

A python app to create autostart profiles on Linux. Select a profile and it starts up a program list for the task at hand. It was made more as a personal utility but figured I should publish it, just in case anyone has the same use case. Tested on Fedora 44 KDE.

## Installation

Install using the included install.sh

```bash
git clone https://github.com/Halodoesanope/AutoMagik.git
cd AutoMagik
chmod +x script.sh
./install.sh
```
