# AutoMagik

A python app to create autostart profiles on Linux. Tested on Fedora 44 KDE. Select a profile and it starts up a program list for the task at hand.

## Installation

Install using the included install.sh

```bash
git clone https://github.com/Halodoesanope/AutoMagik.git
cd AutoMagik
./install.sh
```
